# Contributing

Issues and installation reports are welcome. Start with the included issue template.
Please describe the game build, operating system, reproduction steps, and expected result.
Do not upload saves, extracted game databases, downloaded mod packs, account tokens, or personal paths.

Code and data pull requests are not being accepted for the first public preview.
A contributor agreement covering the project's noncommercial distribution and
separate commercial permissions will be established before accepting outside code.
Do not assume that opening a pull request transfers copyright or grants a commercial license.

Football results should be supported by a link to an official competition or club source.
Use an issue to propose a correction; do not attach a copied third-party database.
